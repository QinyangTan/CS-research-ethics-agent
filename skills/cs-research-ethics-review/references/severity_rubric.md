# Severity Rubric

Consider data sensitivity, identifiability, affected population, vulnerable groups, dual-use potential, deployment context, reversibility of harm, public release risk, missing consent, missing documentation, and confidence.

- Critical: likely severe harm, highly sensitive data, exploit/malware release, exposed secrets, vulnerable population at scale, or public release of identifiable sensitive data.
- High: identifiable personal data, biometrics, surveillance, security dual-use, unclear consent, or public dataset release.
- Medium: public user data, moderate identifiability, scraping without documentation, unclear license, or missing retention policy.
- Low: documentation gaps or speculative risks with limited evidence.

Missing documentation alone should not create a high-severity finding.
