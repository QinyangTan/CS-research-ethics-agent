# Dependency Policy

The package uses lightweight dependencies with bounded version ranges:

- `typer>=0.12,<1.0`
- `rich>=13,<15`
- `pydantic>=2,<3`
- `mcp>=1.0,<2.0`
- `pathspec>=0.12,<1.0`
- `pyyaml>=6,<7`
- `pytest>=8,<9` for tests

MCP clients and agent configuration formats move quickly. The docs provide adaptable examples rather than claiming one universal configuration command.
