# Safe Release Checklist

- [ ] Document purpose, population, and deployment context.
- [ ] Review platform terms, data-source terms, and redistribution limits.
- [ ] Remove or protect identifiers and sensitive attributes.
- [ ] Define retention, deletion, and access controls.
- [ ] Avoid public release of raw sensitive records.
- [ ] Add misuse limitations and safe-use guidance.
- [ ] Prepare responsible disclosure steps for security-sensitive work.
- [ ] Rotate exposed credentials.
